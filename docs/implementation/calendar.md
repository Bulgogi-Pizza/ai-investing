# 경제 캘린더

SOT: docs/planning/requirements.md. 구현: src/features/calendar/CalendarPage.tsx, 필터·날짜 계산: src/lib/market.ts, KST 기준일: src/lib/kst.ts.

## 등록 일정 전용

예시(합성) 일정과 데모 모드는 없다. 화면은 열릴 때 인증된 `/api/calendar/events?from=YYYY-MM-DD&to=YYYY-MM-DD`에서 월 전후 경계 날짜를 포함해 읽는다. 관리자가 출처와 함께 등록한 일정과 공식 RSS 보도자료만 표시하며, 전체 경제 일정의 실시간 공급과 실제 발표치 검증은 미연결이다. 처음 열 때의 월·일은 **오늘(KST)** 이고 "오늘로 이동"으로 돌아온다. 월/주/일/시간 순 타임라인, 이전/다음 기간, 중요도/카테고리/자산/시장 AND 필터, 제목 검색, 이벤트 상세 및 세션 내 관심 저장을 제공한다. 영향 해석에는 출처, 가정, 불확실성, 시계를 표시한다. 모든 시간은 KST다.

상태: 로딩, 조회 실패(경고 + 다시 시도), 등록 일정 없음("등록된 일정이 없습니다", 예시로 대체하지 않음), 조회 한도 초과(`truncated`)를 각각 명시한다.

범위: 이 API는 토스 소유자 계정에 의존하지 않는 공유 등록 자료라 이번 단계에서 소유자 전용으로 제한하지 않았다(로그인한 모든 등록 계정이 읽는다). 등록·수집은 관리자 전용이다. 소유자 전용으로 바꿀지는 아침 갱신(6b) 설계에서 정한다.

## 기간 이동

실제 달력 날짜 산술을 사용한다. 주 시작은 일요일이며 월·연도 경계에서 주/일 이동이 가능하다. 월간 달력의 인접 월 숫자는 비활성화된다. 기간·검색·필터 변경 시 선택 이벤트를 초기화한다. 주간 일정은 일(day) 숫자가 아닌 전체 ISO 날짜와 시각으로 정렬한다(`compareEventTime`).

## 관리자 등록 일정

관리자는 JSON 입력 대화상자로 `POST /api/admin/calendar/events`에 1–100개 이벤트를 등록한다. 서버가 날짜·출처 HTTPS URL·확인시각·영향방향·시계·확신·중복 ID를 검증한 후 ID별 upsert한다. 비관리자는 입력 버튼이 없고 서버가 권한을 검사한다. 상세에는 원문 링크 및 KST 확인시각과 영향 해석의 확신·기간·조건을 표시한다. 여러 영향자산의 어느 태그로든 필터링되며 사용자 정의 카테고리·자산도 필터 옵션에 추가된다. 낮음·보통·높음은 라벨·점 개수·색상으로 구별한다.

## 공식 보도자료 수집

관리자는 공식 출처 목록과 수집 범위 경고를 확인한 후 RSS 가져오기 버튼으로 연준/한국은행의 최근 공개 보도자료를 수집한다. UI는 출처별 synced/cached/failed와 upsert건수·경고를 표시하며 전부 실패하면 실제 오류를 표시한다. 성공 시 일정을 재조회한다. 예약 수집은 없다. API/출처/검증 계약은 [공식 뉴스 공급](news-provider.md)을 따른다. 선택 필드 `eventKind`는 scheduled 또는 news-release이며 news-release의 날짜·시각은 KST 게시시각이지 미래 경제지표 발표가 아니다.
