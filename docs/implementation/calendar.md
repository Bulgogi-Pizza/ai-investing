# 경제 캘린더

SOT: docs/planning/requirements.md. 구현: src/features/calendar/CalendarPage.tsx, 데이터: src/lib/market.ts.

2026년 10월 합성 예시 일정만 제공한다. 실시간 일정 수집과 발표치 검증은 미연결이다. 실제 일정처럼 사용하면 안 된다. 월/주/일/시간 순 타임라인, 이전/다음 기간, 기준일 이동, 중요도/카테고리/자산/시장 AND 필터, 제목 검색, 이벤트 상세 및 세션 내 관심 저장을 제공한다. 다른 월은 빈 상태를 표시한다. 영향 해석에는 출처, 가정, 불확실성, 시계를 표시한다.

검증: `npm test` (데이터 정합성), `npm run test:e2e` (페이지 및 필터), `npm run build`. UI 변경 시 실제 브라우저 확인 필수. 일정은 KST 표기다. 관심 일정은 메모리만 사용한다.

기간 이동은 실제 달력 날짜 산술을 사용한다. 주 시작은 일요일이며 월·연도 경계에서 주/일 이동이 가능하다. 월간 달력의 인접 월 숫자는 비활성화되어 잘못된 날짜 라벨을 만들지 않는다. 기간·검색·필터 변경 시 선택 이벤트를 초기화하여 다른 월의 이벤트가 상세에 남지 않도록 한다. tests/market.test.ts에서 일요일 계산 및 월·연도 이동 경계를 검증한다.

## 관리자 등록 일정

기본 합성 데모와 `등록 일정` 모드를 분리한다. 등록 모드는 인증된 `/api/calendar/events?from=YYYY-MM-DD&to=YYYY-MM-DD`에서 월 전후 경계 날짜를 포함해 읽는다. 전체 ISO 날짜로 월·주·일 범위를 판별하며 여러 영향자산의 어느 태그로든 필터링된다. 사용자 정의 카테고리·자산도 필터 옵션에 추가된다. 오류·미인증 상태는 명시적으로 표시하며 데모 일정으로 대체하지 않는다. 요청 취소 후 상태 갱신을 막는다. 인증이 바뀌면 달력 컴포넌트도 초기화한다.

관리자는 JSON 입력 대화상자로 `POST /api/admin/calendar/events`에 1–100개 이벤트를 등록한다. 서버가 날짜·출처 HTTPS URL·확인시각·영향방향·시계·확신·중복 ID를 검증한 후 ID별 upsert한다. 비관리자는 입력 버튼이 없고 서버가 권한을 검사한다. 대화상자는 필드 형식 도움말을 제공한다. 상세에는 원문 링크 및 KST 확인시각과 영향 해석의 확신·기간·조건을 표시한다. 자동 뉴스 수집이나 생성형 분석으로 표현하지 않는다. 브라우저 데이터는 메모리에만 보관하며 서버 영속화는 서버 저장소 정책을 따른다.

등록 일정의 낮음·보통·높음은 라벨·점 개수·색상으로 구별한다. 주간 일정은 일(day) 숫자가 아닌 전체 ISO 날짜와 시각으로 정렬하여 월·연도 경계를 보존한다. 서버 `truncated: true` 응답은 일부 결과임을 화면에 표시한다. 회귀 검증은 tests/market.test.ts의 중요도/날짜 정렬 단위 테스트와 tests/ui-regressions.spec.ts의 낮은 중요도·결과 잘림·연도 경계 렌더링 테스트를 따른다.
