# 자산 및 전략 — PORT / STRAT

## 구현

`src/features/portfolio.tsx`: 한국어 반응형 자산 대시보드, 평가금액 숨김, 원화/달러 표시, 도넛 자산 구성, 보유자산 표, 집중도·현금·스트레스 시나리오, 목표 비중 편집 및 리밸런싱 금액 계산.

합성 모드의 자산·손익은 **예시 데이터**로 명시한다. 토스 조회 성공 시에는 출처·조회 시각과 함께 실제 주식 잔고 화면으로 전환한다. 달러 환산은 고정 가정 1,350원이며 실환율이 아니다. 스트레스 계산은 주식 −20%, 채권 −3%, 금 +5%, 현금 0% 가정으로 예시 총자산의 −12.6%; 실제 최대낙폭이 아니다. 소득·자산 등 개인 정보를 브라우저 저장소에 보관하지 않는다. 숨김은 표시 기능이며 서버 접근 통제를 대체하지 않는다.

## API 경계

- `/api/auth/me`가 인증을 확인한다. 미인증 사용자는 데모 전략을 현재 컴포넌트 메모리에서만 변경한다.
- 인증 후 `GET /api/strategy`의 저장된 계정 전략을 읽는다. 저장 버튼은 `PUT /api/strategy`에 `{strategy:{name,horizon,benchmark,riskTolerance,targetAllocations,notes}}` 전송. 실제 계좌·거래는 변경하지 않는다.
- `GET /api/portfolio`가 503이면 제공사 연결 대기 메시지를 표시한다. 공식 토스 OpenAPI 스펙을 기준으로 정규화 어댑터와 계약 테스트를 구현했다. 실제 자격증명을 이용한 실계좌 검증은 아직 완료하지 않았다. 성공 시 공식 정규화 계약을 확인하여 실제 주식 화면으로 전환한다.

## 규칙 및 한계

`src/lib/strategy.ts`에서 목표 비중 각 0~100 및 합100% 검사. 금액 차이=(목표%-현재%)*예시 총자산. 세금·비용·유동성 제약은 반영하지 않는다. 투자성향·기간·벤치마크·선호는 저장 가능하나 수익률 비교 계산이나 자동 주문과 연결되지 않는다.

## 검증

`tests/strategy.test.ts`: 비중 유효성, 리밸런싱 총액 보존, 잘못된 입력 거절, 방어 배분 합계 보존. `npm test -- tests/strategy.test.ts`, `npm run build`. 렌더링 검사와 통합 API 검사는 전체 QA 기록을 참조한다. 정적 예시 자산 화면과 실제 데이터 연결 완료를 혼동하지 않는다.

## 공식 API 연결 갱신

공식 Toss Securities OpenAPI 스펙 확인 후 서버 어댑터가 반환하는 정규화 계약을 구현했다. 인증된 `/api/portfolio` 성공 시 합성 예시를 **대체**하여 국내 KRW/해외 USD 평가금액·매입금액·평가손익 및 종목명·종목코드·수량·현재가·평가금액·손익·수익률을 표시한다. 통화별 금액을 합치지 않으며 `source`, `asOf`를 KST로 표시한다. 비어 있는 보유종목은 명시적으로 처리한다.

이 계약의 `scope:'stocks-only'`는 주식 조회 범위다. 현금·채권·금 등 전체 자산을 알 수 없으므로 라이브 모드에서는 자산군 도넛, 전체 비중·스트레스·리밸런싱 계산을 표시하지 않는다. 목표 전략 편집은 계속 가능하다. 미설정503/오류는 명시적 예시로 유지한다. 실키가 없어 실계좌 검증은 미완료이며 서버 계약 테스트와 브라우저 목 응답으로 검증한다.

로그인/로그아웃 시 부모 App이 계정별 key로 컴포넌트를 재생성하여 이전 계정 조회 데이터를 메모리에서 제거해야 한다.

공식 토스 profitLoss.rate는 비율(예:0.1077)로 수신하므로 화면은100을 곱해10.77%로 표시한다. E2E 고정 응답으로 이 변환을 검증한다.
