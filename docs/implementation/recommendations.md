# AI 인사이트 — REC

`src/features/recommendations.tsx`는 **내 데이터 분석**만 제공한다. 합성 예시 모드, 합성 가격·일정 기반 카드, 화면 내 방어 배분 시나리오는 제거했다(`analyzeStrategy`·`defensiveScenario`는 `src/lib/strategy.ts`에 순수 함수로 남아 있으며 화면은 쓰지 않는다). 기본 분석은 설명 가능한 결정 규칙이며 성공확률 예측으로 표현하지 않는다. 선택적인 Vertex 생성형 설명을 별도 카드로 표시할 수 있고, 관리자가 수집한 공식 RSS 보도자료를 최근 뉴스 근거로 구분한다. 실제 키·권한과 운영 공급 연결 검증은 별도 대기 상태다.

## 내 데이터 분석

`GET /api/recommendations?period=daily|weekly|monthly&symbol=005930|000660|AAPL`을 호출한다. 로그인 + **소유자 검사**(서버 `requireOwner`)를 거친다. 서버의 `rules-v1` 계약에 따라 실제 토스 가격, 내 계정 저장 전략 및 출처가 있는 관리자 등록 일정을 분석한다. 화면이 열릴 때와 분석 기간·종목을 바꿀 때 이전 요청을 취소하고 새로 조회한다. 공통 상태 컴포넌트가 원인을 구분한다: 503 `TOSS_INTEGRATION_UNAVAILABLE` 토스 미연결, 403 `OWNER_REQUIRED` 소유자 전용 안내(다른 등록 계정은 이 안내만 본다), 404 `PROVIDER_NOT_FOUND` 해당 종목 데이터 없음, 그 밖의 오류(409 전략 없음 포함)는 서버 메시지와 함께 표시하며 재시도 가능한 오류에는 다시 시도 버튼을 제공한다. **실패 시 합성 결과로 대체하지 않는다**.

성공 응답에는 다음을 표시한다.

- 기간별 수익률·SMA20·RSI14, 가격 시각·조회시각·출처·관측 수.
- 저장 전략의 이름·위험성향·기간·벤치마크·선호·목표 비중.
- 등록 일정의 날짜·중요도·출처 링크·확인시각, 조회범위와 수집범위 경고.
- 일정 없음 및 조회한도 초과를 명시하며 전체 뉴스가 수집되었다고 주장하지 않는다.
- 대안 시나리오와 위험·불확실성, 통화별 주식 내 종목 집중도. 목표 비중과 실제 잔고 비중을 구분한다.

등록 예정 일정은 관리자 선별 입력이다. 공식 RSS 공개 보도자료는 관리자 요청으로 별도 수집하며 전 시장의 완전한 일정이나 전체 뉴스가 아니다. 계좌 노출도도 조회된 주식 범위 내 통화별 비율이며 전체 자산 배분이 아니다. 서버 실데이터 검증과 필수 입력 조건은 `src/server/recommendations.ts`와 금융 서비스 연결 문서를 따른다. 프론트엔드 키나 개인 금융 데이터의 브라우저 영속 저장은 사용하지 않는다. 자동 매매·전략 저장은 수행하지 않는다.

## 검증

`tests/strategy.test.ts`는 저장 계약 파서, 합계/범위/비정상 입력, 리밸런싱 보존, 방어 배분 경계값, 기간별 관찰창을 검사한다. `tests/recommendations-live.spec.ts`(가짜 API `page.route`)는 성공·출처 링크·기간 재조회·합성 예시 버튼 부재 및 503 오류 시 대체 금지를, `tests/app.spec.ts`는 소유자 전용·미연결·빈 데이터·일시 오류 후 재시도를 검증한다. 서버의 소유자 격리는 `tests/market-api.test.ts`, `tests/recommendations.test.ts`가 검사한다. 모든 fixture는 합성이며 실키로 실제 계좌 및 시장 연결을 검증한 것이 아니다. UI 변경 후 데스크톱·모바일 렌더링을 확인한다.

## 예정 일정과 최근 뉴스의 분리

서버는 기존 필드가 없는 이벤트를 scheduled로 취급하고, `eventKind:'news-release'`는 예정 일정 근거에서 항상 제외한다. 뉴스의 게시시각이 미래로 잘못 입력되어도 미래 중요 일정으로 규칙 결정을 바꾸지 않는다. 최근1/7/30일과 현재시각 사이의 공개 보도자료만`evidence.news`에 별도로 제공하며 같은 시장·글로벌·명시적 종목 태그의 관련성 기준을 적용한다. 출처·게시시각·범위·관련성·제외건수·잘림 경고를 별도 최근 뉴스 카드로 표시한다. 제목 기반 중요도는 low확신 추정이므로 그것만으로 규칙 결정을 변경하지 않는다. 미래 중요 일정과 수익률/RSI 기준은 기존 결정 규칙을 유지한다.

## 선택적 생성형 설명

Vertex 어댑터가 활성화되고 서버에서 검증된 결과일 때만 규칙 분석과 분리된 생성형 설명 카드를 표시한다. 모델·분석시계·요약·점검 행동·반대 시나리오·정보 공백·불확실성 및 입력에 포함된 출처 인용을 보여 준다. ready가 아니거나 disabled/unavailable이면 생성형 연결 대기를 표시하고 규칙 결과를 그대로 유지한다. 실패를 성공한 LLM 분석으로 포장하지 않으며, 주문·비중 변경·수익 보장을 수행하지 않는다. 실제 모델/IAM 설정·정보 최소화·응답 스키마 검증은`src/server/ai.ts`와 해당 서버 문서를 따른다.

추가 검증: 뉴스·추천·캘린더 API24개 테스트 통과. `tests/providers.spec.ts`는 RSS 수집과 선택적 Vertex ready/disabled/unavailable 및 최근 뉴스 분리 UI를 합성 응답으로 검사한다. 실제 Gemini/Vertex 호출 성공이나 실계좌 연결 성공을 이 mock 검증에서 주장하지 않는다.
