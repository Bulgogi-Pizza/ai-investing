# 종목 분석 (구 차트 분석)

SOT: docs/planning/requirements.md(ANALYSIS), 설계 [next-phase-design.md 2절](../planning/next-phase-design.md). 구현: `src/features/analysis/`(화면), `src/lib/analysis.ts`·`chartData.ts`·`format.ts`(순수 계산), `src/lib/indicators/`(지표 계산·설명), 서버 `src/server/toss-analysis.ts`·`analysis.ts`, 상태 표시 `src/components/DataState.tsx`, 도움말 `src/components/InfoTip.tsx`. 탭 이름은 "차트 분석"에서 "종목 분석"으로 바꿨다. 이벤트 수직선(5d)과 시장 비교·내 매매 마커(5e)는 이 문서의 범위가 아니다.

## 배치(시안 A)

위에서부터 종목 검색 → 종목 요약 → 기간·지표 선택 → 가격 차트(+별도 패널) → 분석 탭(가치·재무 / 수급 / 호가·체결) → 내 매매 기준선. 종목을 바꾸면 화면 아래 전체가 새로 마운트되어 다른 종목의 값이 섞이지 않는다. 기간·지표 선택은 종목을 바꿔도 유지한다.

## 실데이터 전용 · 소유자 전용

합성 가격과 데모 전환은 없다. 모든 요청은 서버에서 로그인과 **소유자 검사**를 거친다([금융 서비스 연결](integrations.md)). 모든 숫자에는 출처와 조회 시각(KST)을 표시한다. 값이 없으면 대체값을 만들지 않고 사유를 쓴다.

| 상태               | 조건                                                       | 화면                                                         |
| ------------------ | ---------------------------------------------------------- | ------------------------------------------------------------ |
| 토스 미연결        | 503 `TOSS_INTEGRATION_UNAVAILABLE`                         | 연결 설정 안내                                               |
| 소유자 전용        | 403 `OWNER_REQUIRED`                                       | 소유자 전용 안내, 재시도 없음                                |
| **토스 권한 없음** | 403 `TOSS_PERMISSION_DENIED`(토스 데이터 호출의 HTTP 403)  | "토스 권한 없음", 재시도 없음. 일부만 막혀도 나머지는 그대로 |
| 재무 제공자 미연결 | 503 `DART_UNAVAILABLE` / `SEC_UNAVAILABLE`                 | "데이터 제공자가 연결되지 않았습니다"+서버 문구              |
| 데이터 없음        | 404 `PROVIDER_NOT_FOUND`·`FUNDAMENTALS_NOT_FOUND`, 빈 목록 | "표시할 데이터가 없습니다"+다시 조회                         |
| 일시 오류          | 그 밖의 오류                                               | 경고+다시 시도                                               |
| 불러오는 중        | 요청 진행                                                  | 상태 표시                                                    |

현재가와 일봉이 모두 실패하면 화면 전체를 한 번만 안내하고 한 번에 다시 시도한다(같은 원인이 여러 번 반복되지 않게). 일부만 실패하면 그 부분에만 `DataState`를 둔다. 토스에 없는 종목 코드(종목 정보 조회가 빈 결과)는 "종목을 찾지 못했습니다"로 차트·탭을 숨긴다.

## 종목 검색·요약

- 검색: 종목 코드 입력(영문·숫자·`.`·`-` 30자, 서버도 같은 규칙) 또는 자주 보는 종목 칩. 토스 `GET /api/v1/stocks`는 **심볼 목록으로 조회**하며 이름 검색을 지원하지 않는다(명세 v1.2.24). 이름 검색은 `stocks/all`(전체 종목)이 필요해 이번 범위에서 제외했다.
- 종목 정보: 이름·영문명·시장·통화·발행주식수·거래정지·정리매매·상장 상태(`/api/analysis/stocks`).
- 현재가: 기존 `/api/market/prices`. 토스 현재가 응답에는 등락 필드가 없으므로 **등락(원·%)은 일봉으로 계산**하고 기준을 화면에 쓴다("전일 종가 74,520원(2026-10-19 일봉 수정주가 종가) 대비").
- 시가총액: 현재가 × 발행주식수(토스 종목 정보). 계산값임을 표시.
- PER·PBR: `/api/fundamentals`의 `perShare`와 현재가로 `priceRatios`(src/lib/valuation.ts)를 브라우저에서 호출. 표시: "재무 공시일 YYYY-MM-DD · 계산 시각 KST". 값이 없으면 사유(적자, 공시 없음 등).
- 유의사항 배지: `/api/analysis/warnings`(활성 유의사항, 모르는 코드는 그대로 표시), 종목 정보의 거래정지·정리매매, 상하한가 근접. 유의사항이 없으면 "현재 활성 유의사항 없음".

### 계산 규칙(`src/lib/analysis.ts`, 단위 테스트 `tests/analysis.test.ts`)

**등락 기준(전일 대비)**: 일봉은 거래일 현지 자정으로 찍힌다. 현재가 시각이 최신 일봉 시작 시각 이상 24시간 미만이면 최신 일봉은 오늘 봉(진행 중이거나 막 마감)이므로 **그 앞 봉의 종가**가 기준이다. 24시간 이상 뒤면 최신 일봉이 이전 거래일이므로 **최신 일봉 종가**가 기준이다. 현재가 시각이 없거나(`null`), 최신 일봉보다 앞서거나, 비교할 봉이 없으면 숫자를 만들지 않고 사유를 쓴다("등락률 계산 불가"). 미국 장중에도 같은 규칙이다(현지 자정 기준). 일봉 타임스탬프가 현지 자정이 아니면(미확인) 위 규칙이 `STALE_PRICE`로 값을 내지 않는 쪽으로 실패한다. **실제 응답의 타임스탬프 표기는 아직 확인하지 않았다**(고정 IP 실호출 필요).

**상하한가 근접**: 현재가가 상한가까지 **상한가 가격의 2 % 이내**(`(상한−현재가)/상한 ≤ 0.02`)이면 "상한가 근접", 상한가 이상이면 "상한가 도달". 하한은 `(현재가−하한)/하한 ≤ 0.02`. 임계값 상수 `NEAR_LIMIT_RATE`. 전일 종가 대비 등락률이 아니라 한계 가격 자체에 대한 비율이다. 가격 제한이 없는 시장(`null`, 미국)은 판단하지 않고 그렇게 쓴다.

**시가총액** = 현재가 × 발행주식수. 어느 쪽이든 0 이하이면 계산하지 않는다.

## 지표

선택기: `src/lib/indicators/descriptions.ts`의 15종 전부(차트 위에 겹침 8종, 별도 패널 7종. `pane` 값을 따른다). 각 지표 옆 ⓘ 버튼은 마우스 올림·**키보드 포커스**·클릭/탭으로 설명(2~3문장)을 연다. `aria-describedby`로 버튼과 설명을 연결하고 `role="tooltip"`, Esc로 닫는다. 설명 말풍선은 화면 안쪽으로 위치를 보정한다. 기본 선택은 SMA와 RSI. 파라미터는 기본값만 쓴다(조정 UI 없음).

- 계산은 받은 전체 일봉에서 하고(워밍업 구간이 보이지 않게) 선택 기간만 자른다. 워밍업 값은 `null`로 그리지 않는다. 기존 SMA·EMA·볼린저·RSI·MACD는 `src/lib/market.ts`, 추가 지표는 `src/lib/indicators/`.
- 일목균형표: 선행스팬(구름대)을 26봉 앞으로 이동해 미래 구간까지 그린다. 오른쪽 `+N봉`은 거래일이 정해지지 않은 위치이며 날짜가 아니다(화면에 설명). 선행스팬 1≥2/1<2에 따라 구름색을 나눈다.
- VWAP: 일봉에서는 표시 구간 첫 봉부터 누적(구간을 바꾸면 값이 달라짐, 화면에 설명). 피보나치 되돌림: 표시 구간의 고가·저가 기준.
- 기간: 1주·1개월·3개월·6개월·1년·3년(약 5·21·63·126·252·756거래일). 구간이 길면 일봉을 `before`로 더 받는다: 첫 쪽은 200개, 필요한 개수(기간+워밍업 120)가 모자라면 `nextBefore`를 `before`로 넘겨 **최대 5쪽(1,000개 일봉)** 까지만 순차 조회한다. 받은 쪽은 종목별로 보관해 기간을 넓힐 때 모자란 쪽만 더 받는다. 더 오래된 쪽이 실패하면 받은 만큼 표시하고 알린다. 제공된 일봉이 요청 기간보다 적으면 그만큼만 그리고 개수를 알린다. **토스가 일봉을 몇 년 전까지 주는지는 아직 실호출로 확인하지 않았다**(계획 "구현 전 확인 목록").
- 차트 접근성: 차트 컨테이너는 `role="img"`와 요약 `aria-label`을 갖고, 범례를 글로 제공한다.

## 분석 탭

**가치·재무**: EPS·BPS·ROE(TTM)·PER·PBR 카드(각 공시일·계산 시각), 연간(최근 5개)·분기(최근 8개) 표(매출·영업이익·순이익·자산·부채·자본·공시일·출처 링크, KRW 억 원/USD 백만 달러, `*`는 도출한 4분기, 연결/별도 구분). 출처 링크는 https만 링크가 된다. **업종 비교**: 버튼을 눌러 실행(종목마다 재무 공시를 조회하므로 자동 실행하지 않음). 토스 섹터 트리를 위에서부터 찾아 이 종목이 속한 가장 구체적인 업종(비교군 5개 이상인 가장 깊은 업종, 없으면 구성 종목이 가장 많은 업종)을 정하고, 시가총액 상위 **20개**(대상 종목 제외)의 PER·PBR 평균·중앙값·표본 수·제외 수(사유별)를 표로 보여 준다. 20개로 제한한 이유: 종목마다 `/api/fundamentals`를 1회 호출하고(국내는 DART 약 25회) 그 API가 사용자당 분당 30회라서다. 상한에 걸려 잘린 경우 화면에 쓴다. 비교군 값은 종목별로 펼쳐 볼 수 있다. 계산 함수는 `compareSector`(src/lib/analysis.ts) + `sectorSummary`(src/lib/valuation.ts).

**수급(국내만)**: 투자자 동향(외국인·기관·개인·기타법인 순매수 거래량, 외국인 보유율), 공매도, 신용거래, 프로그램매매 각 최근 10거래일. 미국 종목은 "미국 종목은 토스가 제공하지 않습니다"를 표시하고 요청하지 않는다. 시점·정의 주의(장중 잠정치, T+1, KRX·NXT 범위)는 각 표 아래에 쓴다. 선택한 보기만 조회한다.

**호가·체결**: `/orderbook`, `/trades`(최근 20건) 스냅샷. 탭을 열 때 한 번, 이후 "새로 고침" 버튼을 누를 때만 다시 조회한다(자동 갱신·폴링 없음). 체결 방향은 명세에 없어 표시하지 않는다. 최우선 호가 차이는 계산값으로 표시한다.

## 내 매매 기준선

매수·매도 검토선(기본 비어 있음, 입력한 종목의 차트에만 그림, 종목을 바꾸면 초기화)과 가격 메모(현재 세션만)는 그대로다. 이전 화면의 관심종목 토글과 정적 "분석 노트"는 세션 한정 장식이어서 제거했다.
