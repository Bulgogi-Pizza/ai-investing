# 차트 분석

SOT: docs/planning/requirements.md. 구현: src/features/charts/ChartsPage.tsx, 계산: src/lib/market.ts, 상태 표시: src/components/DataState.tsx, 요청: src/lib/api.ts. "종목 분석" 탭으로의 확장(지표 추가, 이름 변경)은 [다음 단계 계획](../planning/next-phase-plan.md) 5단계가 맡는다.

## 실데이터 전용 · 소유자 전용

합성 가격과 데모/실데이터 전환 버튼은 없다. 화면은 열릴 때마다 `GET /api/market/candles?symbol=005930|000660|AAPL&interval=1d&count=100`을 조회한다. 이 API는 로그인과 **소유자 검사**를 서버에서 한다([금융 서비스 연결](integrations.md)). 기능: 삼성전자/SK하이닉스/Apple 선택, 기간(1주/1개월/3개월), SMA20/EMA20/볼린저20(2σ), RSI14(단순 윈도 평균), MACD12/26, 관심종목 토글, 사용자 매수·매도 검토선, 가격 메모(현재 세션만). 자동 주문 없음.

응답의 날짜와 양의 유한한 종가를 검증하고 출처와 조회시간(KST)을 표시한다. 데이터는 조정주가 일봉이며 자동 갱신하지 않는다. 가격 통화는 응답의 `currency`를 따른다(USD는 센트, KRW는 원 단위).

데이터를 받지 못하면 합성 가격으로 대체하지 않고 공통 상태 컴포넌트가 원인을 구분해 보여 준다.

| 상태                  | 조건                                         | 화면                                   |
| --------------------- | -------------------------------------------- | -------------------------------------- |
| 토스 미연결           | 503 `TOSS_INTEGRATION_UNAVAILABLE`           | 연결 설정 안내, 데이터 없음            |
| 소유자 전용           | 403 `OWNER_REQUIRED`                         | 소유자 전용 안내, 재시도 없음          |
| 해당 종목 데이터 없음 | 404 `PROVIDER_NOT_FOUND` 또는 빈 `candles`   | "표시할 데이터가 없습니다" + 다시 조회 |
| 일시 오류             | 그 밖의 오류(제공자 한도·네트워크·형식 오류) | 경고 + 다시 시도                       |

매수·매도 검토선의 기본값은 비어 있다. 값을 입력한 종목의 차트에만 선(線)이 그려지며 종목을 바꾸면 초기화한다(통화 단위가 다르기 때문). 이전의 합성 KOSPI 비교는 제거했고, 시장 지표 비교는 5단계에서 실데이터로 추가한다.

## 계산과 기간

일봉 기간 버튼은 실제 거래일의 대략적인 범위를 표시한다. 1주는 최대5개, 1개월은 최대21개, 3개월은 최대63개의 최신 일봉을 보여준다. 휴장일·제공된 이력 길이 때문에 달력 날짜 범위가 정확히 일주일/한달/세달과 같지 않을 수 있다는 안내를 화면에 표시한다. 지표 warmup을 위해 전체 수신 이력(100봉)에서 지표를 계산한 뒤 표시 구간을 자른다(`chartWindowLength`). `normalizeComparison`은 기준 100 정규화용 순수 함수로 남아 있고 5단계 비교 기능이 재사용한다.

## 추가 지표 계산

SOT: docs/planning/next-phase-design.md(종목 분석 탭), 구현: `src/lib/indicators/`, 테스트: `tests/indicators.test.ts`. 모두 입력을 바꾸지 않는 순수 함수이며 입력은 오래된 봉부터 정렬된 OHLCV(`{timestamp, open, high, low, close, volume}`)다. 기존 `market.ts`의 SMA·EMA·볼린저·RSI·MACD는 그대로 두고, 화면 연결은 별도 단계에서 한다. 설명 문구와 겹침/별도 패널 구분은 `descriptions.ts`가 가진다(지표 15종 각각 ⓘ 툴팁 2~3문장, 기본 파라미터 문자열, `pane: 'price' | 'separate'`).

공통 규칙:

- 모든 파라미터는 기본값을 가지며 양의 정수·허용 범위를 검사해 잘못되면 `함수명: 파라미터 ...` 형식의 오류를 던진다.
- 데이터가 부족한 워밍업 구간은 항상 `null`이다. 0이나 NaN을 쓰지 않는다. 결과 길이는 입력 길이와 같다. 예외는 일목균형표(입력 + 전진 이동 길이)다.
- 분모가 0이 되는 평평한 가격은 지표별로 중립값을 정해 아래에 적었다. 거래량 합이 0이면 VWAP은 값을 만들지 않고 `null`이다.
- 지표용 EMA는 처음 `period`개 종가의 SMA로 시작해 워밍업을 명시한다. 기존 `market.ts`의 `ema`는 첫 값으로 시작하므로 값이 다르다.

세부 선택:

- 일목균형표: 반환 배열은 `candles.length + displacement`개이며 마지막 `displacement`개는 봉이 아직 없는 미래 위치다. 이 위치에는 구름(선행스팬 A·B)만 값이 있고 나머지는 `null`이다. 각 점의 `senkouA`·`senkouB`는 이미 앞으로 이동한 위치의 값이고 `chikou`는 `index+displacement` 봉의 종가다(마지막 `displacement`개 봉 위치에는 값이 없다).
- VWAP 앵커: 분봉은 `anchor: 'session'`(기본)으로 세션 키가 바뀔 때마다 누적을 다시 시작한다. 기본 세션 키는 ISO 타임스탬프의 날짜 부분(제공된 표기 그대로, 숫자 타임스탬프는 UTC 날짜)이다. 한국 시각으로 자정을 넘는 미국장 등은 `sessionKey`로 직접 지정한다. 일봉은 하루 단위로 초기화하면 VWAP이 그날 대표가격과 같아지므로 `anchor: 'cumulative'`로 `anchorIndex`부터 누적한다.
- 스토캐스틱: 평활 3을 쓰는 슬로를 기본으로 한다. 패스트는 `kSmoothing: 1`로 얻는다.
- ATR·ADX: 윌더 평활을 쓰며 ATR 첫 값은 첫 봉의 고−저를 포함한 TR 평균이다(인덱스 `기간−1`). 첫 봉 TR을 제외하고 `기간` 인덱스에서 시작하는 구현과 처음 몇 값이 다를 수 있다.
- OBV: 시작 값을 0으로 두므로 절댓값은 받은 이력의 시작점에 따라 달라지고 의미는 기울기와 가격과의 방향 일치에 있다.
- 파라볼릭 SAR: 결과는 `{sar, trend}`이며 `trend`('up'/'down')로 점을 가격 아래·위 어느 쪽에 그릴지 정한다. 초기 추세는 둘째 봉 종가가 첫 봉 종가 이상이면 상승이다.
- 피보나치 방향: 최저가가 최고가보다 먼저면 상승 후 되돌림으로 보고 0%=고가, 100%=저가로 아래로 그린다. 최고가가 먼저면 하락 후 반등으로 보고 0%=저가, 100%=고가로 위로 그린다. 극값이 같은 가격으로 반복되면 처음 봉을 쓰고, 극값이 한 봉에 겹치면(단일 봉·평평한 가격) 상승으로 둔다. `direction`으로 직접 지정할 수 있다.
- 검증: 모든 지표를 손으로 계산한 작은 고정 입력으로 확인하고(계산식은 테스트 주석), 워밍업 `null`, 평평한 가격, 파라미터 오류, 출력 길이, 입력 불변을 `tests/indicators.test.ts`에서 고정한다.
