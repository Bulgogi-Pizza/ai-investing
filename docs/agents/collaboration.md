# 협업 운영

AGENTS.md가 Codex·Claude·Gemini 공통 지침의 유일한 원본이다. CLAUDE.md, GEMINI.md는 진입점이다. 작업 시작 시 요구사항·아키텍처·해당 기능·상태 문서를 읽는다.

감독은 파일 소유권을 나누어 병렬 작업을 배정하고, 의존성을 알리고, 테스트·접근성·보안·재사용성·화면 품질을 근거로 검토한다. 작업 중에도 독립 작업을 계속한다. 요청 모델은 GPT Terra/Claude Sonnet을 우선한다. 최초 협업 런타임에서는 해당 모델 선택이 불가능하여 기본 Codex 에이전트3개가 UI/서버/자산·추천을 분담했다. 이후 감독이 로컬 Claude CLI의 `--model sonnet`으로 별도 읽기 전용 보안 리뷰를 실제 수행했다. 리뷰에는 `git archive`로 만든 공개 소스의 정제된 사본만 제공했으며 실제 자격증명이나 개인 금융 데이터는 제공하지 않았다. 리뷰에서 수용한 개선 항목은 영속 요청 제한, 추천 기간 검증, WIF 배포 경계 강화이며 세부 판단과 결과는 감독의 별도 리뷰 기록을 따른다. GPT Terra 또는 Gemini를 실행했다고 주장하지 않는다.

완료 보고에는 변경 파일·검증 결과·남은 제한을 포함한다. 한 기능 변경 시 기능 문서와 테스트를 함께 갱신한다. 인증/인프라/데이터 연동 변경은 별도 보안 검토 대상으로 한다.

2026-10-21 다음 단계 실행: 감독은 Claude Opus(Claude Code 데스크톱)였다. 단계별 구현과 독립 읽기 전용 보안 검토는 Claude Sonnet 하위 에이전트가 각자의 git worktree 브랜치에서 맡았다. 감독은 모든 diff를 직접 검토했고, 지시 위반·보안 문제는 되돌려 고치게 했다. 통합 충돌 해결, Terraform plan·apply, 운영 실행 확인도 감독이 했다. 보안 검토는 단계 3, 7d, 7e·7f에서 했다. 7d에서는 높음 1건(실행 겹침 이중 주문)이 나왔고, 반영한 뒤 병합했다. GPT Terra와 Gemini는 쓰지 않았다.
