# 협업 운영

AGENTS.md가 Codex·Claude·Gemini 공통 지침의 유일한 원본이다. CLAUDE.md, GEMINI.md는 진입점이다. 작업 시작 시 요구사항·아키텍처·해당 기능·상태 문서를 읽는다.

감독은 파일 소유권을 나누어 병렬 작업을 배정하고, 의존성을 알리고, 테스트·접근성·보안·재사용성·화면 품질을 근거로 검토한다. 작업 중에도 독립 작업을 계속한다. 요청 모델은 GPT Terra/Claude Sonnet을 우선하지만 현재 협업 런타임에서 선택 불가하므로 사용 가능한 기본 Codex 에이전트3개로 UI/서버/자산·추천을 분담했다. Claude/Gemini 실행 또는 리뷰를 수행했다고 주장하지 않는다.

완료 보고에는 변경 파일·검증 결과·남은 제한을 포함한다. 한 기능 변경 시 기능 문서와 테스트를 함께 갱신한다. 인증/인프라/데이터 연동 변경은 별도 보안 검토 대상으로 한다.
