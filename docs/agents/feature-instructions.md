# 기능별 추가 지침

공통 정책 SOT: ../../AGENTS.md. 새 대화에서 전역 지침은 AGENTS.md, 기능 한정 지침은 이 문서 또는 관련 기능 문서에 반영한다.

- 인증: 우회 경로가 없는지 서버 통합 테스트로 확인한다. 관리자 초기 생성은 터미널 보안 입력으로 수행하며 비밀번호를 명령행 인수에 쓰지 않는다.
- 캘린더: KST 날짜 경계와 여러 필터 교집합을 검증한다. 예시 이벤트는 실제 발표 일정이라고 주장하지 않는다.
- 차트: 서로 다른 가격대 비교는 기준100으로 정규화한다. 지표는 실제 계산하고 데이터 부족 구간을 구분한다.
- 전략: 비중100%와 입력 범위를 검사한다. 리밸런싱은 참고 계산이며 주문으로 연결하지 않는다.
- 추천: 규칙 기반 결과를 생성형 AI 결과라고 표현하지 않는다. 원천 데이터·관측 기준·조건·무효화 근거를 함께 기록한다.
