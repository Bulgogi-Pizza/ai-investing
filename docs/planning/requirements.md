# 요구사항 SOT

기준: 2026-10-21 Asia/Seoul. 개인 투자 도구. 커뮤니티는 제외한다. 실제 주문은 소유자 전용 알고리즘 실전 운용에서만, [설계](next-phase-design.md) 4절의 안전장치를 모두 통과할 때 허용한다. 그 외 기능은 주문하지 않는다.

| ID       | 기능                      | 수용 조건                                                                                                                                         |
| -------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| AUTH     | 관리자 등록 계정만 로그인 | 공개 가입 없음, 서버 권한 검사, 비활성화 시 기존 세션 차단                                                                                        |

| DOC      | 협업                      | 공통 AGENTS.md, CLAUDE.md/GEMINI.md 진입점, 기능과 문서 동시 변경                                                                                 |

실데이터와 데모를 명시적으로 구분한다. 데이터/API 키가 없으면 실제 연동 완료를 주장하지 않는다. 토스 API의 공개 마케팅 안내는 제공 범위 근거일 뿐 인증·엔드포인트·응답 스펙을 대신하지 않는다. 계약이 확인되기 전 연동은 차단 상태로 구현한다.

참고: ExcelKospi의 밀도 높은 시장 정보/관심종목; 토스증권의 읽기 쉬운 종목·계좌 동선; Investing의 중요도·시장별 경제 캘린더. 외부 사이트를 크롤링해 무단 재배포하지 않는다. 라이선스와 계약이 확보된 공급자를 사용한다.

다음 단계(실데이터 전환·종목 분석·알고리즘 자동 매매) 확정 설계: [next-phase-design.md](next-phase-design.md), 구현 계획: [next-phase-plan.md](next-phase-plan.md). 계획의 1단계(규칙 문서 변경)가 이 표에 반영되었다. ANALYSIS·ALGO·NOTIFY·BRIEF·SCOPE는 목표 수용 조건이며 구현 여부는 [상태 SOT](../implementation/status.md)를 따른다. 구현 전에는 완료로 주장하지 않는다.

변경 규칙: 요구사항 수정 → 관련 기능 문서 및 테스트 수정 → 공통 검증 → 렌더링 확인 → 상태 SOT 기록. 이후 대화의 전역 지침은 AGENTS.md, 기능 지침은 docs/agents/feature-instructions.md에 반영한다.
