# 독립 검토 및 판정

2026-10-20. 사용자가 요청한 Claude Sonnet을 로컬 Claude Code CLI `--model sonnet`으로 호출했다. git archive로 이미 공개된 추적 소스만 별도 임시 폴더에 복사하고 restricted 모드, Read/Grep/Glob만 허용, MCP 차단, 파일 수정 금지로 검토했다. 비공개 환경파일·개인 계정 설정·고객 데이터는 전달하지 않았다. API 예산$1.5/5턴 제한의 제한적 검토이며 전체 보안 감사로 표현하지 않는다.

## 지적과 처리

| 지적                                        | 사실 확인과 조치                                                                                                                                                                                                                              |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| scale-to-zero에서 로그인 제한 초기화        | 수용. Firestore 공유 트랜잭션으로 IP와 계정별 제한, 운영에서 필수 주입, TTL 설정 추가                                                                                                                                                         |
| 모든 중요 일정이 모든 종목의 위험 신호가 됨 | 수용하되 미국 CPI가 한국 주식과 무관하다고 단정하지 않음. 초기 규칙을 요청 시장·글로벌·명시 종목 태그로 제한하고 제외 건수/범위를 노출                                                                                                        |
| 1주7봉/1개월30봉/3개월전체100봉 불일치      | 수용. 약5/21/63거래일과 명시적 안내. 지표는 워밍업을 위해 전체 이력으로 계산한 뒤 표시 기간만 자름                                                                                                                                            |
| 수익률 비율/퍼센트 단위 가정                | 변경 불필요. 공식 예제0.1077과 평가손익700,000/매입6,500,000≈0.1077을 확인했고100을 곱해10.77%로 표시/브라우저 테스트 중. 리뷰는 이 스키마를 확인하지 못했다고 명시했음                                                                       |
| 배포 신뢰 범위·가변 action 태그             | 수용. OIDC workflow_ref/production 환경/workflow_run 이벤트 추가 제한, Artifact Registry 개별 저장소 IAM, 모든 Action SHA 고정. 프로젝트run.admin은 최초 서비스 생성/IAM bootstrap을 위해 전용 프로젝트 내 제한으로 유지하고 운영 문서에 명시 |

일반 job에는 reusable workflow용 job_workflow_ref 대신 [공식 GitHub OIDC 문서](https://docs.github.com/en/actions/reference/security/oidc)의 workflow_ref를 사용한다. 결과는 Codex 감독자가 근거를 확인하고 수정 또는 기각했다.
