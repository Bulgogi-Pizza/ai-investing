## 직접 렌더링 검사

IAB에서 경제 캘린더·차트·자산 화면을 렌더링해 확인했고 Playwright가 저장한 데스크톱 AI 인사이트와 모바일 자산 전체 화면 PNG도 시각 검사했다. 가로 오버플로는 모든 페이지 E2E에서 확인한다. 데모 라벨, 본문/카드 간격, 도넛·지표 차트, 전략 입력/비율 검증, 통화 분리, 로그인 접근을 확인했다.

화면 PNG는 개인정보 혼입 방지를 위해 저장소에 넣지 않고 `.local/qa/`에 생성한다. `npm run test:e2e`의 capture rendered visual evidence 테스트로 재생성 가능하다. 실제 자산·등록 일정 경로는 HTTP fixture를 주입해 데모 혼입 방지와 수익률0.1077→10.77% 변환을 검증했다.

## 발견 및 수정

- 주간 시작일 및 월 경계 탐색 계산, 선택 일정 잔존, 모바일 로그인 접근.
- 로그인/로그아웃 시 개인 데이터 컴포넌트 초기화.
- 토스 수익률의 비율값과 퍼센트 표시 변환.
- 공식 토스 IP 허용 조건에 맞춘 고정 출구 IP/NAT 구성.
- Firestore 구버전 uuid 및 테스트 런타임 취약점: 지원 버전으로 갱신 후 전체audit0.
- Vite major 업그레이드 후 기존 미리보기 서버 캐시 때문에 브라우저 테스트가 실패했으나 서버 재시작 후 전체14개 통과. CI는 새 서버를 시작한다.

실제 GCP 배포·Firestore 영속 접근·토스 OAuth/계좌 호출은 아직 검증하지 않았다. 이를 위 자동 테스트 통과로 대체하지 않는다.

추가 회귀: 연도 경계 일정 정렬, 낮은 중요도,USD 소수점, 기간별 기준100,일정잘림 안내,실제 규칙 추천 성공/오류.

GitHub 최초 CI에서 앱/인프라/운영 컨테이너 검증은 성공했으나 추천 화면 캡처의 macOS 전용 `/private/tmp` 경로가 Linux에서 없어 E2E2건이 실패했다. 경로를 Playwright `testInfo.outputPath`로 변경하여 플랫폼 공통 테스트 아티팩트 디렉터리를 사용한다. 기능 단정22건은 해당 원격 실행에서도 통과했다. 후속 CI 결과 확인 전 전체 원격 성공이라고 기록하지 않는다.
