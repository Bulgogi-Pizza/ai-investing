## 직접 렌더링 검사

IAB에서 배포된 경제 캘린더를 열어 확인했다. 데스크톱·모바일 자동 테스트는 모든 페이지 가로 넘침, 로그인 접근, 차트 지표, 통화·수익률, 필터·날짜 경계, 등록 근거와 합성 데이터 분리, 뉴스·AI 성공/오류 화면을 확인한다. 캡처 PNG를 직접 열어 뉴스 수집 카드·AI 해설·최근 뉴스 카드·관리자 상단 메뉴를 검사했다.

모바일 관리자 메뉴가 화면 너비390px를 넘어가는 결함을 수정했고 모든 페이지에서 계정 등록·로그아웃 접근과 가로 넘침 회귀 테스트를 추가했다. 뉴스·AI 카드의 작은 글씨는 본문12px/안내11px 이상으로 키우고 긴 출처명 줄바꿈을 검증했다. 화면 PNG는 개인정보 혼입을 방지하도록 gitignore된 `.local/qa/`에만 저장한다. `npm run test:e2e`로 재생성한다.

## 검증의 범위

- RSS/AI 테스트는 고정 URL, redirect금지, XML외부엔티티 차단, 입력·응답 크기와 시간 제한, 권한, 실패·부분성공, 단일호출 캐시, 공유25회 한도 및 TTL을 확인한다.
- AI는 규칙 결과를 바꾸지 않는 별도 해설이다. 출력 형식·근거 ID·주문 문구 검사만으로 의미 정확성을 보장하지 않는다.
- 실제 토스 OAuth·계좌·시세 호출은 아직 검증하지 않았다. 이 제한을 UI와 상태 SOT에 표시한다.
- 초기 CI의 macOS 전용 캡처 경로를 Playwright 아티팩트 경로로 수정한 PR12와, 공유 로그인 제한·WIF를 보완한 PR14는 각각 필수3개 CI 통과 후 병합했다.
- 독립 Claude Sonnet 보안 리뷰의 판단은 independent-review.md를 따른다.

추가 독립 Codex 검토에서 신규 비중 설정 지시의 출력 검증 누락과 캐시 수집의 반복 저장 비용을 지적했다. 출력 문구 검사·회귀 사례와 수집 전용15분3회 제한을 보완했다. 패턴 검증이 의미 정확성을 보장한다고 주장하지 않는다.

개인 프로젝트 Terraform apply 완료 후 재계획 결과 No changes로 실제 리소스와 코드 일치를 확인했다. Vertex API·런타임IAM·aiUsage TTL도 적용되어 있다.
